# 🏍️ Harley-Davidson Showroom & Custom Garage Website

Website profil *showroom*, katalog penjualan unit, dan bengkel modifikasi kustom Harley-Davidson dengan tampilan *dark-mode* yang gagah, modern, dan profesional.

## ✨ Fitur Utama
- **Desain Dark-Mode Futuristik:** Memadukan warna gelap yang elegan dengan aksen tegas, menonjolkan kesan maskulin dan premium khas dunia motor kustom.
- **Katalog Unit & Mahakarya Kustom:** Menampilkan etalase unit Harley-Davidson (*Brand New* & *Certified Pre-Owned*) serta hasil modifikasi *custom build*.
- **Informasi Layanan Lengkap:** Mencakup penjualan motor (*Motorcycle Sales*), fabrikasi & restorasi (*Custom Build*), hingga perawatan mesin & suku cadang (*Service & Spare Parts*).
- **Responsif di Semua Perangkat:** Dibangun menggunakan *framework* CSS **Bootstrap 5** sehingga tampilan tetap optimal dan rapi baik dibuka melalui desktop, tablet, maupun *smartphone*.
- **Struktur Kode Rapi:** Pengkodean HTML dan CSS terstruktur dengan baik, memudahkan proses pemeliharaan maupun pengembangan fitur di masa mendatang.

## 🛠️ Teknologi yang Digunakan
- **HTML5**
- **CSS3** (Custom Dark-Mode Styling)
- **Bootstrap 5**

## 📂 Struktur Bagian Halaman
1. **Hero / Banner:** Pengenalan singkat *showroom* dengan tombol navigasi cepat menuju katalog.
2. **About Us:** Profil *dealer* dan bengkel kustom beserta keunggulan layanan.
3. **Our Services:** Rincian layanan utama (*Sales*, *Custom Build*, dan *Maintenance*).
4. **Our Catalog:** Galeri foto unit motor yang tersedia dan portofolio hasil modifikasi.
5. **Contact Us:** Peta lokasi *showroom*, informasi alamat, jam operasional, serta kontak WhatsApp dan email untuk konsultasi maupun *booking*.
